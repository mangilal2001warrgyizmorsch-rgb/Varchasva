# Frontend Rules

- **Framework:** Use Next.js App Router paradigms (Server Components by default, use `"use client"` only when necessary for interactivity).
- **Styling:** Use Tailwind CSS for all styling. Do not write custom CSS unless absolutely required for complex animations not solvable by Tailwind/Framer.
- **Animations:** Use `framer-motion` for complex, high-quality, premium animations.
- **Responsive Design:** Mobile-first approach using standard Tailwind breakpoints (`sm`, `md`, `lg`, `xl`).
- **Reusable UI:** Never create duplicate components when an existing reusable component can be used.
- **21st.dev:** Prioritize ready-made premium components from 21st.dev as requested by the source Google Doc tutorial.
