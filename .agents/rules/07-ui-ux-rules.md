# UI/UX Rules

- **Core Inspiration:** The design must look professional, modern, and high-converting (as detailed in the "How To Build a $10,000 Website Using AI" tutorial).
- **Premium Components:** Source components from `21st.dev` for complex UI pieces (Hero, Testimonials, Pricing).
- **Skill Usage:** Use the `ui-ux-pro-max` skill for design intelligence, style keywords, and layout structures.
- **Consistency:** Maintain consistent spacing, typography, and colors across the application.
- **Animations:** Smooth transitions are mandatory using Framer Motion. Ensure animations serve a purpose (e.g., drawing attention, signaling interaction).
