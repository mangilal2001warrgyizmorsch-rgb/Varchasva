# Core Rules

## Priority Behaviors
1. **Analyze Before Modifying**: Never modify code without understanding its context.
2. **Minimal Changes**: Make the smallest safe change required to achieve the goal.
3. **Reuse Existing**: Always prefer using existing components and dependencies over adding new ones.
4. **No Secrets**: Never expose API keys, OAuth tokens, passwords, or database credentials.
5. **Verify**: Never claim a task is complete without testing and verifying the changes.
6. **No Silent Failures**: Never suppress errors or warnings unless explicitly documented.
7. **Production Ready**: Keep code production-ready and maintain backward compatibility.
