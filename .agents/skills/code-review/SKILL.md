# Code Review

**Checklist:**
- [ ] Correctness: Does it solve the problem?
- [ ] Security: Are there injection risks or exposed secrets?
- [ ] Performance: Are there unnecessary re-renders or heavy imports?
- [ ] Maintainability: Is it clean, documented, and properly typed?
- [ ] Architecture: Does it follow `.agents/rules/`?
- [ ] Duplication: Can we use an existing component?
