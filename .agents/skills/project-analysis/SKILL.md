# Project Analysis

Use this skill to deeply understand the project state.

**Workflow:**
1. Inspect `package.json` for dependencies.
2. Read `.agents/rules/` for architectural constraints.
3. Trace data flows through components using tools like `grep_search`.
4. Produce a detailed implementation plan before writing code.
