# Bug Fixing

**Workflow Sequence:**
1. **REPRODUCE:** Confirm the bug exists.
2. **DIAGNOSE:** Trace logs and errors.
3. **ROOT CAUSE:** Find the exact line/logic at fault.
4. **FIX:** Implement the minimal required fix.
5. **TEST:** Verify the fix works.
6. **REGRESSION CHECK:** Ensure nothing else broke.
7. **REPORT:** Summarize the fix.
