# Feature Development

**Workflow Sequence:**
1. **ANALYZE:** Understand requirements and existing implementation.
2. **PLAN:** Find reusable components, plan the architecture.
3. **IMPLEMENT:** Make the code changes safely.
4. **VALIDATE:** Run linters and type checkers.
5. **TEST:** Manually or automatically test functionality.
6. **REVIEW:** Check `git diff`.
7. **REPORT:** Provide a clear summary to the user.
